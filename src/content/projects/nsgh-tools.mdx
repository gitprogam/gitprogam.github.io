## 시작은 한글 파일이었어요

학교에서 받는 안내문이나 과제 양식은 거의 다 HWP 잖아요. 근데 정작 개인 노트북이나 컴퓨터실에는 한글이 안 깔려 있는 경우가 많아서, 파일은 있는데 못 여는 일이 학기마다 반복됐어요.

변환 사이트야 인터넷에 많죠. 근데 무료라고 해 놓고 결과 받으려면 가입하라거나, 하루 몇 번까지만 된다거나, 광고 창을 몇 번 닫아야 다운로드 버튼이 나오는 데가 대부분이더라구요... 급한 사람한테 그런 거 안 시키는 곳 하나쯤은 있어도 되겠다 싶어서 만들었습니다.

## 뭐가 있냐면

[북곽툴즈](https://tools.binaryhub.club/)는 가입도 설치도 없이 쓰는 문서 도구 모음이에요. 제일 많이 쓰는 건 한글·워드·엑셀·PPT 를 PDF 로 바꾸는 거고, 그 밖에 PDF 합치기/나누기, PDF 를 이미지로 뽑기, JPG·PNG·WebP·아이폰 HEIC 사진 변환 같은 게 있어요. 자주 쓰는 서식 내려받기랑, 수업 시간에 자리 뽑기나 모둠 나눌 때 쓰는 도구도 같이 넣어 뒀습니다.

변환 조합마다 안내 페이지도 따로 만들었어요. "hwp pdf 변환" 같은 걸 검색해서 들어온 사람이 들어오자마자 바로 변환할 수 있게요. 올린 파일은 그 변환에만 쓰고 끝나면 지워요. 변환 기록이나 보관함 같은 건 안 남깁니다.

## 어떻게 만들었냐면

Next.js 16(App Router) + React 19 + TypeScript + Tailwind 4 조합이에요. 페이지를 서버에서 그려서 보내니까 검색엔진이 내용을 바로 읽을 수 있고, 변환 요청 받는 API 도 같은 앱 안에 있어요.

DB 는 아예 없어요. 파일 받아서 임시 폴더에서 처리하고, 결과 돌려주고, 폴더째 지우는 구조라 저장할 게 없거든요. 대신 서버가 넉넉한 편이 아니라서 한 사람이 짧은 시간에 보낼 수 있는 요청 수랑 동시에 돌리는 변환 수에는 제한을 걸어 뒀어요.

새 버전 올릴 때는 같은 앱을 두 벌 띄워 놓고 프록시가 가리키는 쪽만 바꿔요. 그래서 배포 중에도 사이트가 안 끊깁니다. 서버 돌리는 얘기는 [BinaryHub 운영기](/projects/binaryhub-ops/)에 따로 써 놨어요.

## 한 도메인에 Next.js 앱이 두 개?

원래 북곽툴즈는 `tools.binaryhub.club` 에 있었고, 루트 `binaryhub.club` 은 동아리 서비스 링크만 모아 둔 페이지였어요. 근데 광고 심사는 루트 도메인을 보는데, 링크 모음 페이지는 본문이 500자 남짓이라 많이 불리하더라구요. 그래서 제일 많이 쓰이는 북곽툴즈를 루트로 올리기로 했습니다.

문제는 루트에 남아 있어야 하는 옛 앱(부원 블로그 같은 거)도 Next.js 였다는 거예요. 둘 다 정적 파일을 `/_next/` 로 부르니까 같은 도메인에 그냥 두면 서로 파일을 가려 버려요. 그래서 옛 앱 쪽 경로를 `/_bb/_next/` 로 비켜 두고(`assetPrefix`), 프록시가 `/_bb` 를 떼서 옛 앱으로 넘기게 했어요. 옛 앱엔 정해 둔 몇 개 경로만 보내고, 나머지는 전부 북곽툴즈가 받습니다.

옮기는 순서도 미리 짰어요. 아무 영향 없는 프록시 경로부터 추가하고 → 옛 앱 배포 → 북곽툴즈 배포 → 마지막에 루트 전환. 덕분에 옮기는 동안 끊긴 페이지는 없었어요 ㅎㅎ

옛 주소는 경로 그대로 붙여서 새 주소로 301 시켰는데, `/api/` 밑에 오는 요청만은 예외로 계속 받아요. 301 받으면 POST 를 GET 으로 바꿔 버리는 클라이언트가 있어서, 옛 주소로 변환 요청하는 데가 남아 있으면 그대로 깨지거든요.

해 보니까 경로 충돌은 눈에 보이는 페이지 주소보다 정적 파일, 업로드 이미지, 로그인 콜백 같은 안 보이는 경로에서 터지더라구요.

근데 2주쯤 굴려 보니 굳이 이럴 이유가 없었어요. 그래서 10월 26일에 원래대로 되돌렸어요. 루트는 다시 동아리 포털이고, 북곽툴즈는 `tools.binaryhub.club` 이에요. 그 2주 동안 루트 주소로 검색에 잡힌 도구 페이지는 경로 그대로 tools 쪽으로 301 보내고, `/api/` 는 이번에도 리다이렉트 없이 그대로 받게 했어요. 올릴 때 붙였던 canonical 수정(대표 주소가 상대 경로로 나가던 버그)은 주소만 바꿔서 그대로 뒀고요.
