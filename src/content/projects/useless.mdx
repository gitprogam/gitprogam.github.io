## 이름 그대로 쓸모없는 앱

[무쓸모.앱](https://useless.binaryhub.club/)은 진짜 쓸모가 없어요 ㅋㅋ 정성스럽게 만든 가짜 사물 세 개를 모아 놨어요.

- **온라인 화장실:** 회사나 학교에서 도저히 화장실을 못 갈 때, 변기 그림 보면서 물이라도 한 번 내리기
- **온라인 에어컨:** 전기세 0원. 실제 온도는 그대로인데 눈이랑 귀로는 시원함
- **온라인 선풍기:** 화면 가까이서 보면 그래도 좀 시원함. 1·2·3단에 회전까지 됨

가짜라도 만지는 맛은 진짜처럼 하고 싶었어요. 화장실은 물 내리면 3초 동안 다시 못 누르고, 지금까지 물 내린 횟수가 쌓여요. 휴지를 당기면 바닥에 휴지 조각이 떨어지는데 열두 장 넘게는 안 쌓여요. 에어컨은 전원, 설정 온도, 냉방·제습·송풍 모드, 바람 세기 5단계를 고를 수 있고, 바람을 세게 하면 화면 속 바람도 빨라져요. 켜면 본체 구석 작동 표시등이 초록색으로 바뀌고 2초마다 천천히 깜빡여서 진짜 돌아가는 것처럼 보여요.

선풍기 날개는 CSS 애니메이션으로 돌려요. 한 바퀴 도는 데 1단은 0.8초, 2단은 0.45초, 3단은 0.25초로 정해 놨고, 단계가 오를수록 앞으로 흘러가는 바람 줄기도 빨라지고 촘촘해져요. 회전을 켜면 선풍기 머리가 4초에 한 번씩 좌우로 왔다 갔다 해요. 페이지 맨 밑에는 "실생활에 도움 0% · 만족 약간%"라고 적어 놨어요.

## 소리는 직접 만들었어요

가짜 사물이 그럴듯하려면 소리가 중요하더라구요. 물소리, 바람 소리, 에어컨 소리를 녹음 파일로 넣을 수도 있었는데, 그러면 파일을 따로 받아야 하고 단계마다 소리 바꾸기도 귀찮아요. 그래서 녹음 파일은 하나도 안 쓰고 브라우저의 Web Audio API 로 소리를 직접 만들었어요.

방법은 이래요. 2초짜리 백색잡음(치이이익 하는 소리)을 한 번 만들어 두고 계속 반복 재생해요. 이걸 특정 높이 소리만 통과시키는 필터(밴드패스)랑 높은 소리를 깎는 필터(로우패스)에 차례로 통과시키면, 필터를 어떻게 잡느냐에 따라 물소리 같기도 하고 바람 소리 같기도 해요. 선풍기 단계를 올리면 소리 크기랑 필터 높이를 같이 올려서 바람이 세지는 것처럼 들리게 했어요.

변기 물 내리는 소리는 3초짜리로 따로 만들었어요. 3초 동안 필터 높이를 크게 움직여서 "쏴아아" 하고 쓸려 내려가는 느낌을 내고, 소리 크기는 처음에 확 올렸다가 천천히 줄이면서 끝내요.

잡음은 처음 한 번만 만들고 계속 재활용해요. 브라우저는 사용자가 뭔가 누르기 전엔 소리를 못 내게 막아서, 오디오는 처음 버튼 누를 때 시작하고 멈춰 있으면 다시 깨워요. 물 내린 횟수 같은 기록은 서버로 안 보내고 각자 브라우저 저장소에만 남겨요.

## 서버가 할 일이 없어서 옮김

처음엔 다른 서비스들처럼 동아리 PC 에서 돌렸어요. 근데 생각해 보니 이 앱은 서버가 할 일이 하나도 없어요. 저장하는 데이터도, 서버 기능도, 숨길 비밀값도 없고, 전부 브라우저 안에서 끝나요.

그래서 2026년 6월에 Next.js 를 정적 파일로 내보내게(`output: "export"`) 바꾸고 Cloudflare Pages 로 옮겼어요. 정적 내보내기에서는 Next.js 이미지 최적화 서버를 못 써서 이미지 최적화도 끄고, 빌드한 결과물을 직접 올리는 식으로 배포해요. 따로 서버가 안 도니까 PC 에서는 이 앱이 먹던 메모리 250MB 정도를 아꼈어요. 사이트마다 어디에 둘지 정한 기준은 [BinaryHub 운영기](/projects/binaryhub-ops/)에 써 놨어요.

장난으로 만든 거지만 건진 건 있어요. 녹음 파일 없이 잡음이랑 필터 몇 개로 꽤 그럴듯한 소리가 나온다는 거, 그리고 "이거 진짜 서버가 필요한가?"부터 따져 봐야 한다는 거요.
